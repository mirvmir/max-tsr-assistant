# Демонстрация

Запустите сервисы по [README](../README.md). Все сведения пользователя в сценарии учебные.

```bash
docker compose exec app tsr demo --dataset public --scenario both --download-dir /tmp/tsr-demo --show-dialog
mkdir -p var/demo
docker compose cp app:/tmp/tsr-demo/. var/demo/
```

Команда использует PostgreSQL, application, очереди, worker и рендер документов. Сетевой обмен MAX заменён локальным транспортом. Сценарии работают в отдельной области кейсов и очередей.

Цена выбранной комплектации в снимке каталога: **14 500 ₽**. Условное покрытие: **10 000 ₽**. Условная разница: **4 500 ₽** (`450000` копеек). Условия доставки и приём сертификата уточняются у продавца, поэтому итог с доставкой остаётся неизвестным.

Ожидаемый результат: `purchase: ready; files=1; gap=450000 kopeks`. PDF содержит выбранное изделие, параметры, расчёт, источники и вопросы продавцу. Хеш предварительного результата совпадает с хешем manifest.

## Обращение

Тот же выбор используется для учебного маршрута `ru-alt`. Подтвердите сведения демонстрационного заявителя и предварительный результат.

Ожидаемый результат: `support: ready; files=4; gap=450000 kopeks`.

| Файл | Содержание |
| --- | --- |
| Заявление DOCX | Редактируемый черновик |
| Заявление PDF | Версия для просмотра |
| Карточка ТСР PDF | Выбранное изделие и расчёт |
| Чек-лист PDF | Сведения и приложения для обращения |

Все документы содержат маркировку DEMO и относятся к одному manifest.

## Дополнительные режимы

```bash
docker compose exec app tsr demo --dataset public --scenario both --role representative
docker compose exec app tsr demo --dataset synthetic --scenario both
```

`representative` использует роль представителя. Набор `synthetic` содержит пять учебных предложений и эталонную разницу 20 000 ₽.

## Проверка в MAX

После [подключения бота](integrations/MAX.md) пройдите обе ветки в мобильном и веб-клиенте:

1. Выберите роль, введите и подтвердите параметры. Используйте «Не знаю», «Назад» и «Помощь».
2. Просмотрите страницы предложений, выберите комплектацию и проверьте источники и расчёт.
3. Измените ответ и подтвердите обновлённый результат.
4. Скачайте документы, затем откройте их через «Мои материалы».
5. Вернитесь к кейсу через «Мои кейсы» и проверьте сохранение ответов.
6. Удалите учебный кейс с подтверждением и проверьте закрытие доступа к материалам.
