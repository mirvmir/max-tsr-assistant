После независимой повторной проверки контроллером (12 HTTPS GET, 151 успешная проверка) реальные каталог, предложения, реестр и записи источников получили `review.status=reviewed`, `reviewer_id=codex-root-public-fact-audit`, `reviewed_at=2026-09-30T01:10:11.200322Z`, `review_due_at=2026-10-07T01:10:11.200322Z`. Это фактическая техническая сверка публичных данных, не утверждение медицинских правил. Доказательства: [FACTUAL_AUDIT.md](FACTUAL_AUDIT.md) и [factual-audit.json](factual-audit.json). Дата первого наблюдения отдельно сохраняется и не подменяется датой проверки. Технический профиль и сведения пользователя остаются явно синтетической моделью; медицинские правила D01 не утверждены экспертом.

Файлы: `data/catalog/mvp/1.1.0/catalog.json` — используемый CatalogPack; `normalized_catalog.json` рядом — идентичная нормализованная выгрузка; `data/sources/1.1.0/sources.json` — реестр; `data/evidence/public-*/2026-09-30/facts.json` — фактические извлечения; `data/releases/real-1.1.0/manifest.json` — смешанный demo release. ## Что именно считается комплектацией

Ortonica предоставляет в HTML `characteristicsOrderEditorConfig.selectedOfferId` и массив `OFFERS`. Для каждой строки сохранено ровно одно выбранное предложение: `selectedOfferId` → запись `OFFERS[ID]` → её `DISPLAY_PROPERTIES` и `ITEM_PRICES[ITEM_PRICE_SELECTED]`. `seller_sku` — публичный ID торгового предложения, не выдуманный артикул. Артикулы, показанные в карточке, дополнительно сохранены в фактическом извлечении и configuration. Цена относится только к этому ID и размеру; соседние размеры не получили цену по умолчанию.

У Ortonica Base 145 отображаются два артикула: 00032214 и 145001711; выбранное предложение имеет ID 324, сиденье 43 см. Оба артикула записаны без предположения, что они взаимозаменяемы. Для Base 200 ID 5048 на странице показан артикул 00031193.

У Medicamarket используется опубликованный «Код товара» и `JSON-LD Product.sku`. Для SKU 00-00048577 (Base 300, пневмошины, 45,5 см) H1, параметры, видимая цена и `Product.offers.price` согласованы: 20 046 руб. Это `exact` для этой выбранной SKU. SEO-заголовок страницы содержит «от» как общее описание семейства; другие варианты не выделены в дополнительные строки и не получили эту цену.

Для Base 200 SKU 00-00046407 заголовок сообщает литые шины, таблица — пневматические. Конфликт записан в configuration и evidence; не созданы фиктивные две комплектации. Цена «от 16 724» остаётся `from`, не точным расчётом.

Для Base 350 SKU 00-00048705 и Base 400 SKU 00-00048697 в блоке заказа явно «От …» и `PreOrder`; цены 20 988 и 23 628 руб. сохранены как `from`, наличие `on_order`.

Для Base Lite 350 SKU 00-00048067 верхний блок сообщает «нет в наличии», JSON-LD — `PreOrder`. Это `Fact.conflicting` с альтернативами `out_of_stock` и `on_order`, а не подтверждённое наличие. Показанная цена «от 29 986» не используется для точного расчёта. Описание упоминает другую модель Base 195; параметры взяты из таблицы и выбранной SKU, свойства другой модели не переносились.

Для Base Lite 300 SKU 00-00048055 видимая цена/SEO — 33 141 руб., `JSON-LD Product.offers.price` — 31 957 руб. Обе суммы сохранены в `Fact.conflicting`, `price_kind=unknown`; расчёт price/coverage/gap/total не выполняется.

Страница Medicamarket Base 450 в прямом запросе ответила HTTP 404 и исключена. МЕГА-ОПТИМ FS681 имеет санитарное оснащение и раздел кресло-стул; исключена из выбранного общего набора ручных колясок. Кешированные публикации не подменяют эти проверки.

## Единицы и неизвестные условия

Ширина берётся из физического значения конкретной комплектации, не из списка вариантов и не из округлённой подписи кнопки. В частности, кнопка Ortonica «40» не означает 400 мм: `DISPLAY_PROPERTIES` у SKU 5048 содержит 40,5 см, что даёт **405 мм**. Преобразование выполнено десятичной арифметикой: см × 10 = мм; 45,5 см → 455 мм, 38 см → 380 мм, 43 см → 430 мм. Значения кг не меняют единицу; максимальная нагрузка 130 кг сохраняется как опубликованная характеристика. Складная конструкция подтверждена выбранной карточкой: механизм «Ножницы» либо `Тип рамы=складная`.

Все значения помещены в исходные wrapper DTO (`QuantityValue`, `MoneyValue`, `BooleanValue`, `CodeValue`) и сопровождаются `SourceEvidence` с URL через реестр, locator и observed_at. Диапазоны и перечни семейства не превращались в точный размер.

Для всех 12 предложений доставка остаётся `mode=unknown` и charge/terms unknown. Общее `JSON-LD shippingRate=0` у Medicamarket не доказывает стоимость конкретного заказа для региона пользователя. Его значение намеренно не преобразовано в «доставка включена».

Кнопка оплаты сертификатом/общая услуга магазина отмечена в evidence, но успешная оплата точной SKU в конкретном заказе не проверена. `accepts_certificate=unknown`, а не true. Пользовательская декларация применимости также не является проверкой реестра сертификата. `has_fund_contract=unknown`: приём сертификата и договор фонда независимы, публичного доказательства второго не получено.

## Проверяемый первый сценарий

Синтетический ввод: ширина назначения 405 мм, масса пользователя 100 кг, складная конструкция true, заявленная сумма сертификата 10 000 руб., заявленная применимость yes. Выбор: Ortonica Base 200, SKU 5048; snapshot `079f6eca-6fb4-5b90-b7ca-c21d0d290113`.

Публикация выбранной комплектации: сиденье 405 мм, нагрузка 130 кг, цена 14 500 руб. Техническое сравнение трёх полей — complete; это не медицинское заключение. При неизвестном приёме сертификата условное покрытие — 10 000 руб., разница — 4 500 руб. (`certificate_use=conditional`); итог с доставкой — null, `pricing.status=incomplete`. Нулевая доставка и одобренная помощь фонда не выдуманы. При явном ответе «сертификат не применим» покрытие = 0, разница = 14 500 руб. независимо от неизвестного приёма продавцом.

## Контроль происхождения и использование

Сохраняются только фактические извлечения, без текстов отзывов, имён покупателей и изображений. У каждого извлечения есть URL, дата прямого наблюдения, locator, SHA-256 исходного HTTP body и отдельный SHA-256 сохранённого facts.json в SourceRecord. После независимого повторного GET добавлены ссылка на точную запись factual-audit.json, время проверки, HTTP Date и SHA-256 повторно проверенного body. HTTP Date означает получение ответа, а не дату публикации продавцом. Хеш сохранённого извлечения дополнительно входит в manifest. Исходный полный body не включён в Git: права на массовое переиздание текстов и фото не установлены. Подтверждение качества factual snapshot и лицензия на страницу — разные вопросы.

Смешанный release явно оставляет технический профиль, пользователя, модель маршрута и созданные шаблоны синтетическими draft. Реальные цены/параметры помечены отдельно. Пилот и медицинская пригодность не объявляются проверенными. Public draft не активируется. Для этих 12 публичных предложений независимая фактическая проверка завершена, review evidence записаны честно; модельный профиль, маршрут и шаблоны остаются draft и допускаются только отдельным demo-флагом. Для пилота необходимы собственные предметные проверки маршрута, правил профиля и шаблонов.

`tests/test_real_catalog.py` содержит независимые численные ожидания для SKU 5048, условной разницы 4 500 руб., from-price, конфликтов цены и наличия, 12 уникальных SKU и хешей evidence. После записи разрешённого результата независимой проверки targeted suite `tests/test_real_catalog.py`, `tests/test_domain.py`, `tests/test_releases.py` прошёл **18 тестов** с реальной временной PostgreSQL. Итоговый manifest: valid, 0 ошибок, 24 файла; generic loader загрузил все 12 предложений с точными метками reviewed public snapshot / draft synthetic model.
